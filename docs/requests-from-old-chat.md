# Requests from the old chat

Every request, change and preference the owner gave in the old project chat "Multi-agent AG-UI hackathon project"
(17 to 26 Nov 2026), checked against `main` at `2e19715` on Thu 26 Nov 2026 and updated as the gaps were closed. Screenshots from that chat are in the
project files under `artifacts/screenshots/`, and the design documents under `knowledge/claude/`.

Status: **Done** means it is on `main` and covered by a browser check or a unit test. **Partly** means the main idea
is there and a piece is missing. **Missing** means it is not built. **Dropped** means the owner later chose
otherwise. The last column names the pull request that closes a gap, or the thread that owns it.
