# The React port

The workspace in `src/legacy` was written for htm and Preact and is kept byte for byte. It runs on React 19 through
`src/platform/compat` and `src/platform/boot.ts`, which put React behind the names the modules already read from the
page (`html`, `render`, hooks, `ReactDOM.createRoot`). This page lists each difference between the two libraries that
the layer handles, why, and which test would fail if it stopped working.

Tests: unit tests are in `tests/unit` (jsdom). Browser checks are in `tests/e2e/flows.cjs`; the flow named `react`
holds the checks that only React can get wrong, and the other eight flows (286 checks) exercise everything else.

## Things React does that the checks watch for

Flow `react` fails on: any console error or warning, or page error, from sign-in through a full build of the clinic
template; a caret that jumps; a handler that runs twice; no focus inside a new dialog; Escape not closing it; the
`/spike` page not drawing its canvas.

Focus is not moved by the layer. A dialog puts focus inside itself when it opens (`Dialog` in `src/legacy/ui.js`).
If the focused button is removed by a later render, focus falls back to the page, in Preact and React alike, so a key
press goes nowhere until something inside the dialog is focused again.
