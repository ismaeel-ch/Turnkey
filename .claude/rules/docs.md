# Documentation

- Plain English, short sentences, no marketing words. Say what the thing does and how to check it.
- Describe what exists. Mark anything planned as planned. Do not invent numbers, benchmarks or quotes.
- Diagrams are Mermaid code blocks so they render on GitHub and can be reviewed as text.
- Never include a key, a real gateway address, or client or internal company data, in text or in screenshots.
